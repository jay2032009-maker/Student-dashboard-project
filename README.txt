STUDENT DASHBOARD CONCEPT
This is a front-end portfolio concept built with HTML, CSS and JavaScript.

Features:
- Student overview cards
- CGPA and attendance
- Subject attendance
- Assignment tracker
- Student profile
- Responsive sidebar navigation
- Mobile menu

Interview explanation:
"I created this Student Dashboard concept to show how a real college portal could organize academic information. HTML provides the structure, CSS creates the dashboard layout and responsive design, and JavaScript handles the mobile sidebar. The sample data is static because this is a front-end concept. In a full-stack version, I would connect it to a Python Flask/Django backend and a database."
